# 한자 타이핑

일본 상용한자 2136자의 음독·훈독을 한글(또는 가나)로 직접 입력하며 익히는 웹 타이핑 게임입니다.
지하철 노선도 타이핑 게임에서 아이디어를 얻어 만들었습니다.

**Play**: https://kanji-typing.vercel.app <!-- 실제 배포 주소로 교체 -->

---

## 무엇을 할 수 있나요

- 한자가 뜨면 음독 / 훈독 칸에 각각 정답을 입력
- 읽기가 여러 개인 한자는 하나만 맞혀도 통과, **정답 보기**를 누르면 전체 읽기를 한 번에 확인
- 히라가나 · 가타카나 · 한글 표기 모두 정답으로 인정
- 장음 표기(こう → 코 / 코우), じゃ·じゅ·じょ·ちゃ·ちゅ·ちょ 요음(주 / 쥬 등) 처럼 표기 방식이 갈리는 부분은 **둘 다 정답 처리**
- 한자 완료 시 한국 한자음(훈+음)도 함께 표시

## 학습 범위

문부성 학년별한자배당표(2020년 개정 기준) + 常用漢字表 전체를 담았습니다.

| 구분 | 글자 수 |
|---|---|
| 1~6학년 (교육한자) | 1,026자 |
| 초급 (1~6학년 통합) | 1,026자 |
| 중고급 (교육한자 이외 상용한자) | 1,110자 |
| 전체 랜덤 | 2,136자 |

음훈독 데이터는 자체 CSV를 기반으로 하되, [cjkvi-tables](https://github.com/cjkvi/cjkvi-tables)의 常用漢字表 데이터와 전수 대조하여 누락된 읽기를 모두 보완했습니다.

## 난이도

| 난이도 | 통과 조건 |
|---|---|
| 쉬움 | 음독·훈독 중 아무거나 하나만 맞으면 통과 |
| 보통 (기본값) | 음독 1개 + 훈독 1개 맞히면 통과 |
| 어려움 | 그 한자의 음독·훈독 전부를 맞혀야 통과 |

## 이번주 도전

전체 2,136자 중 랜덤 20문항을 매주 월요일 0시(로컬 기준)마다 새로 뽑습니다.
같은 주에 접속한 모든 사용자는 **동일한 문제**를 풀게 되며(시드 고정 셔플), 별도의 주간 랭킹이 쌓입니다.

## 랭킹

- Firebase Realtime Database 기반 전 세계 랭킹
- 학년 · 문항 수 · 난이도 조합별로 랭킹이 분리 저장됩니다
- 어뷰징 방지를 위해 정답 보기 사용 비율이 전체 문항의 20%를 넘으면 랭킹 등록이 제한됩니다
- 브라우저에도 개인 최근 기록 5개가 별도로 저장됩니다

## 기술 스택

- Vanilla HTML / CSS / JavaScript (별도 빌드 과정 없음, 단일 파일)
- Firebase Realtime Database (전 세계 랭킹)
- 폰트: Nanum Gothic(본문), Noto Serif JP(한자 표시), JetBrains Mono — 전부 Google Fonts CDN

## 로컬에서 실행하기

빌드 과정이 없는 단일 HTML 파일이라 별도 설치 없이 바로 열어도 됩니다.

```bash
git clone https://github.com/filmlet1/kanji-typing.git
cd kanji-typing
# index.html을 브라우저로 열면 끝
```

랭킹 기능까지 테스트하려면 `index.html` 안의 `firebaseConfig`를 본인 Firebase 프로젝트 값으로 바꿔주세요.
